# Lab 6: Quizzler - Modularising & Organising Flutter Code

A TypeScript React Native quiz using the original four Vietnamese true-or-false questions. It tracks question progress, correct and incorrect answers, the score, and supports a fresh restart.

## Run on Android

```sh
cd source
npm install
npm run android
```

Requirements: Node.js 22.11 or newer, Java, Android Studio/SDK, and an Android emulator or device. Build a release APK with `cd source/android && ./gradlew assembleRelease`.

The release app was built and launched on the Pixel 7 Android emulator. I answered the questions, checked the score and answer history, reached the result screen, and verified restart. The local demo video is stored separately from this repository.
